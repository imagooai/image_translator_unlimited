**Image Translator Unlimited**（[translate.imagoo.ai](https://translate.imagoo.ai)）は、Windows / macOS 向けの**ローカル AI 画像翻訳**デスクトップアプリです。**写真・スクリーンショット・漫画・コミック・文書画像**内のテキストを翻訳。**無制限バッチ処理**、**アップロード制限なし**、**完全プライバシー**—すべてお使いの PC 上で動作します。

多くの画像は **1〜2 秒**で処理完了。翻訳後は**背景・文字・フォント・色・エフェクト**を調整して仕上げられます。**数十の主要言語**に対応し、**Google** や **OpenL** などの翻訳サービスとも連携可能です。

## FAQ

**Image Translator Unlimited / translate.imagoo.ai とは？**  
Image Translator Unlimited は、画像内テキストを OCR で検出し、翻訳して元文字を除去し、翻訳文を画像に再描画する**AI 画像翻訳ツール**です—すべてお使いの PC 上で動作します。

**Windows と Mac に対応していますか？**  
はい。**Windows 64 ビット**、**macOS Apple Silicon**、**macOS Intel** 用インストーラーを提供しています。

**バッチ画像翻訳に対応していますか？**  
はい。複数画像を選択し、バッチタスクをキューに追加、出力を自動保存—繰り返しアップロード/ダウンロードは不要です。

**ローカルで動作しますか？**  
はい。ローカルエンジンが端末上で画像を処理し、翻訳済み画像は指定フォルダに保存されます。

**対応言語は？**  
英語、日本語、韓国語、フランス語、イタリア語、タイ語、ロシア語、スペイン語、ベトナム語、ドイツ語、アラビア語など数十言語。Google や OpenL との連携も可能です。

**安全なダウンロード先は？**  
このリポジトリの **Releases**、または公式サイト [translate.imagoo.ai](https://translate.imagoo.ai) のみからダウンロードしてください。

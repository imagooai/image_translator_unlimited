**Image Translator Unlimited**([translate.imagoo.ai](https://translate.imagoo.ai))는 Windows 및 macOS용 **로컬 AI 이미지 번역기** 데스크톱 앱입니다. **사진, 스크린샷, 만화, 코믹, 문서 이미지** 안의 텍스트를 번역합니다. **무제한 일괄 처리**, **업로드 제한 없음**, **완전한 프라이버시**—모든 처리가 사용자 컴퓨터에서 실행됩니다.

대부분의 이미지는 **1~2초** 안에 처리됩니다. 번역 후 **배경, 텍스트, 글꼴, 색상, 효과**를 조정해 더 깔끔한 결과를 만들 수 있습니다. **수십 개의 주요 언어**를 지원하며 **Google**, **OpenL** 등 번역 서비스와 연동할 수 있습니다.

> 검색 팁: **Image Translator Unlimited**, **translate.imagoo.ai**, 또는 *AI 이미지 번역기*, *이미지 속 텍스트 번역*, *일괄 이미지 번역*, *로컬 OCR 번역기*, *만화 번역기*, *스크린샷 번역기*.

## FAQ

**Image Translator Unlimited / translate.imagoo.ai란?**  
Image Translator Unlimited는 이미지 내 텍스트를 OCR로 인식하고, 번역한 뒤 원문을 제거하고 번역문을 이미지에 다시 렌더링하는 **AI 이미지 번역 도구**입니다—모두 사용자 컴퓨터에서 실행됩니다.

**Windows와 Mac에서 사용할 수 있나요?**  
네. **Windows 64비트**, **macOS Apple Silicon**, **macOS Intel**용 설치 파일을 제공합니다.

**일괄 이미지 번역을 지원하나요?**  
네. 여러 이미지를 선택해 일괄 작업을 큐에 넣고 출력을 자동 저장—반복 업로드/다운로드가 필요 없습니다.

**로컬에서 실행되나요?**  
네. 로컬 엔진이 기기에서 이미지를 처리하며, 번역된 이미지는 선택한 폴더에 저장됩니다.

**어떤 언어를 지원하나요?**  
영어, 일본어, 한국어, 프랑스어, 이탈리아어, 태국어, 러시아어, 스페인어, 베트남어, 독일어, 아랍어 등 수십 개 언어. Google 및 OpenL 연동 가능.

**안전한 다운로드 경로는?**  
이 저장소의 **Releases** 또는 공식 사이트 [translate.imagoo.ai](https://translate.imagoo.ai)에서만 다운로드하세요.

**Image Translator Unlimited** ([translate.imagoo.ai](https://translate.imagoo.ai)) ist ein **lokaler KI-Bildübersetzer** und eine **Desktop-App** für Windows und macOS. Übersetzen Sie **Text in Fotos, Screenshots, Manga, Comics und Dokumenten**—mit **unbegrenzter Batch-Verarbeitung**, **ohne Upload-Limits** und **voller Privatsphäre**, da alles auf Ihrem Computer läuft.

Die meisten Bilder werden in **1–2 Sekunden** verarbeitet. Nach der Übersetzung passen Sie **Hintergrund, Text, Schriftarten, Farben und Effekte** an. Unterstützt **Dutzende wichtiger Sprachen** und Integration mit Übersetzungsdiensten wie **Google** und **OpenL**.

## Installation

### Windows

1. Laden Sie die Windows-`.exe` von Releases herunter.
2. Führen Sie den Installer aus und folgen Sie den Anweisungen.
3. Starten Sie **Image Translator Unlimited** über das Startmenü oder die Desktop-Verknüpfung.

### macOS

1. Laden Sie die `.dmg` für **Apple Silicon** oder **Intel** herunter (passend zu Ihrem Mac).

## FAQ

**Was ist Image Translator Unlimited / translate.imagoo.ai?**  
Image Translator Unlimited ist ein **KI-Bildübersetzungstool**, das Text erkennt (OCR), übersetzt, das Original entfernt und die Übersetzung ins Bild zurückrendert—alles auf Ihrem Computer.

**Ist Image Translator Unlimited für Windows und Mac verfügbar?**  
Ja. Installer für **Windows 64-Bit**, **macOS Apple Silicon** und **macOS Intel**.

**Unterstützt es Batch-Bildübersetzung?**  
Ja. Mehrere Bilder auswählen, Batch-Aufgaben einreihen und Ausgaben automatisch speichern—ohne wiederholtes Hoch- und Herunterladen.

**Läuft es lokal?**  
Ja. Die lokale Engine verarbeitet Bilder auf Ihrem Gerät. Übersetzte Bilder werden in von Ihnen gewählten Ordnern gespeichert.

**Welche Sprachen werden unterstützt?**  
Dutzende wichtiger Sprachen u. a. Englisch, Japanisch, Koreanisch, Französisch, Italienisch, Thai, Russisch, Spanisch, Vietnamesisch, Deutsch und Arabisch. Integration mit Google und OpenL möglich.

**Wo lade ich Image Translator Unlimited sicher herunter?**  
Nur von den **Releases** dieses Repositorys oder der offiziellen Website [translate.imagoo.ai](https://translate.imagoo.ai).

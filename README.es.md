**Image Translator Unlimited** ([translate.imagoo.ai](https://translate.imagoo.ai)) es un **traductor de imágenes IA local** y una **aplicación de escritorio** para Windows y macOS. Traduce **texto en fotos, capturas de pantalla, manga, cómics y documentos**—con **procesamiento por lotes ilimitado**, **sin límites de subida** y **privacidad total**, porque todo se ejecuta en tu ordenador.

La mayoría de las imágenes se procesan en **1–2 segundos**. Después de traducir, ajusta **fondos, texto, fuentes, colores y efectos** para un resultado más limpio. Admite **decenas de idiomas principales** e integración con servicios de traducción como **Google** y **OpenL**.

## Instalación

### Windows

1. Descarga el `.exe` de Windows desde Releases.
2. Ejecuta el instalador y sigue las instrucciones.
3. Abre **Image Translator Unlimited** desde el menú Inicio o el acceso directo.

1. Descarga el `.dmg` para **Apple Silicon** o **Intel** (según tu Mac).
2. Abre la imagen de disco y arrastra **Image Translator Unlimited** a Aplicaciones.

## FAQ

**¿Qué es Image Translator Unlimited / translate.imagoo.ai?**  
Image Translator Unlimited es una **herramienta de traducción de imágenes IA** que detecta texto (OCR), lo traduce, elimina el original y renderiza la traducción en la imagen—todo en tu ordenador.

**¿Está disponible para Windows y Mac?**  
Sí. Instaladores para **Windows 64 bits**, **macOS Apple Silicon** y **macOS Intel**.

**¿Admite traducción de imágenes por lotes?**  
Sí. Selecciona varias imágenes, encola tareas por lotes y guarda las salidas automáticamente—sin subir y descargar archivos repetidamente.

**¿Funciona en local?**  
Sí. El motor local procesa las imágenes en tu dispositivo. Las imágenes traducidas se guardan en las carpetas que elijas.

**¿Qué idiomas admite?**  
Decenas de idiomas principales incluyendo inglés, japonés, coreano, francés, italiano, tailandés, ruso, español, vietnamita, alemán y árabe. Integración con Google y OpenL.

**¿Dónde descargar Image Translator Unlimited de forma segura?**  
Solo desde los **Releases** de este repositorio, o el sitio oficial [translate.imagoo.ai](https://translate.imagoo.ai).

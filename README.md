## FAQ

**What is Image Translator Unlimited / translate.imagoo.ai?**  
Image Translator Unlimited is a desktop **AI image translation tool** that detects text in images (OCR), translates it, removes the original text, and renders the translation back into the image—entirely on your computer.

**Is Image Translator Unlimited available for Windows and Mac?**  
Yes. Installers for **Windows 64-bit**, **macOS Apple Silicon**, and **macOS Intel**.

**Does it support batch image translation?**  
Yes. Select multiple images, queue batch tasks, and save outputs automatically—no need to upload and download files repeatedly.

**Does it run locally?**  
Yes. The local engine processes images on your device. Processed images are saved to folders you choose.
